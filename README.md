# Ruokareitti – vierailumuistiinpanot

Kevyt, asennettava PWA-sovellus Ruokareitti #4 -vierailujen havaintojen kirjaamiseen.

## Käyttö

- Lisää jokainen vierailukohde omaksi lomakkeekseen.
- Kirjaa havainnot kolmen teeman ja niiden kysymysten alle.
- Tiedot tallentuvat automaattisesti käytettävälle laitteelle ja selaimeen.
- Ota varmuuskopio ennen selaimen tietojen tyhjentämistä tai laitteen vaihtamista.
- Valitse **Tulosta / tallenna PDF** tehdäksesi tulostettavan yhteenvedon.

Sovellus toimii myös ilman verkkoyhteyttä, kun se on avattu ainakin kerran verkossa.
